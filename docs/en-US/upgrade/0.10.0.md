# Upgrade to 0.10.0

This version focuses on drawing: a shared 51-tool catalog, multiline text, handles and precision coordinates, object management, groups, templates/preferences, and explicit chart/workspace/host scopes. KLineCharts remains pinned to 10.1.0. Local builds and version strings do not imply npm or Pages publication.

## Migrating from 0.9.0

- Public layout capture/restoration uses ChartLayoutV4 and named workspaces use WorkspaceDocument v2. Read `drawings`, `drawingPresentation`, optional `sharedDrawingRefs`, and workspace `sharedDrawings` instead of `chart.overlayData`. Backend content remains with the host; layouts store its presentation/references.
- Use migrateLayoutToV4, captureLayout/restoreLayout and saveLayoutV4/loadLayoutV4. Legacy chart v1/v2/v3 and workspace v1 are read and migrated without overwriting originals. Index-only legacy points require the original loaded history. saveLayoutV3 is no longer exported publicly.
- Adopt user content through commitDrawing or restoreDrawings. A matching ID cannot grant editing permission over a host overlay. Register a real template before importing a custom catalog tool.
- UI and programmatic commands share executeDrawingCommand. Inspect completed/partial/rejected/uncertain/cancelled and per-item results. Confirmed prefixes are retained; unknown writes are never replayed automatically. Legacy undo/redo methods use the same queue and cancel old queued operations after a context change.
- Multiselection reports null through the old single-ID onDrawingSelect callback. onDrawingStateChange returns copied state; onDrawingHistoryChange follows the actual operation session. Consecutive migration undo/redo keeps the operation history; an explicit selection changes the target.

Defaults: Alt+T finite trend line, Alt+H horizontal, Alt+V vertical, Alt+F Fibonacci, Alt+R rectangle, Alt+B brush, Alt+C cross line, Shift+M measurement. Measurement moves from Alt+M to Shift+M; Alt+C creates a cross line rather than also toggling the crosshair. Ctrl/Cmd undo and copy/paste preserve native behavior in inputs. Per-instance preferences reject conflicting and reserved combinations.

## Persistence and ownership

Preferences are session-only unless a host explicitly provides the first-party IndexedDB preferences store and an opaque drawingPreferencesScope. Charts borrow stores; the final owner disposes them. SSR does not open IndexedDB.

Host sharing requires a DrawingSessionRegistry, a DrawingDocumentStore, and resolveDrawingShareKey. Identity includes namespace, market/exchange/ticker/priceCurrency and a confirmed price basis. Only local market anchors in the main price pane are shared. Original price values project onto each chart's main price axis, without persisting one instance's engine axis ID. Indicator-pane, logical-future and viewport drawings stay chart-local; backend annotations retain their original host authority.

A null expectedRevision means create-only CAS. An unknown response is reconciled by reading the same fixed documentId, preserving drafts and transfer recovery records. The independent [drawing workbench example](https://github.com/evotrader/TradingChest/tree/main/examples/drawing-workbench) includes real IndexedDB and an optional loopback HTTP contract server; that server's records last only for its process.

## Geometry and interaction

Regression uses loaded OHLC OLS and population residual deviation. Fibonacci, channels and forks calculate original prices before axis projection. Measurements distinguish bar counts from elapsed time. Position tools expose price, explicit ticks, percentages and reward/risk only. Invalid directions, zero risk and non-positive log-domain results are explained.

Enter or Finish completes variable-point tools; Escape cancels; Space temporarily pans. Handles support arrow keys and Shift 10px steps. Completed drags submit once. IME composition does not confirm text; Ctrl/Cmd+Enter confirms multiline content. Future anchors show subsequent bars without invented market dates.

See the [coverage and differences](../drawings-coverage.md). Volume profiles, Anchored VWAP, curves/arcs, additional Gann/Fib/wave tools, images, drawing alerts and order integration remain later candidates. The 51 tools do not imply full TradingView tool parity.
