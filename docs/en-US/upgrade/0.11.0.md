# Upgrade to 0.11.0

This version adds Anchored VWAP, Fixed Range Volume Profile, collapsible groups, a virtualized object tree and confirmed reordering. The catalog grows from 51 to 53 tools. KLineCharts remains pinned to 10.1.0. See the [volume drawing contract](../drawings.md#volume-drawings). Local release materials do not imply external publication.

## Integration and migration

No new Datafeed methods are required. Both tools consume this chart loader’s confirmed OHLCV. Volume must exist, be finite and nonnegative. Sources without volume retain all previous tools and receive an explicit unavailable reason for these tools. Unknown units remain provider volume units. These are current-period estimates, not trade-level distributions or aggressor buy/sell volume.

ChartLayoutV4, WorkspaceDocument v2 and shared document v1 continue storing definitions. Stable IDs are `anchoredVwap` and `fixedRangeVolumeProfile`. Parameters and market anchors persist; calculated curves, bins and status do not. Existing 0.10 tools need no migration. Older readers must preserve and reject unknown tools rather than silently drop them and overwrite the document.

Optional `DrawingState.analytics` contains copied summaries by logical ID. `DrawingAnalyticsState` and related types are exported from root, `chart` and `solid`. Coverage is explicitly unknown beyond loaded bars; `period` may be absent before data confirmation.

Absolute ordering uses `{type:'reorder', ids, targetId, position:'before'|'after'}` in displayed tree order. Existing direction commands remain supported. Targets must be writable objects in the same document, scope, pane and group. Locked, migration and uncertain objects are rejected. Execution rechecks current state and uses existing undo/redo history.

## Interaction and limits

The tools require real market timestamps on the main price pane. Anchor movement edits time only; endpoint prices do not participate in calculations. Replay consumes only its visible prefix and reports an incomplete right boundary. Shared definitions recalculate independently at each chart’s current period.

Collapsed groups last for the current session; search temporarily expands matches. Arrow/Home/End navigation retains focus across virtualization. Pointer dragging and target selectors execute the same confirmed command. Existing CAS, unknown-write reconciliation and borrowed-resource ownership remain unchanged.

Standard deviation bands, finer-timeframe/trade profiles, curves/arcs and drawing alerts remain future candidates. TradingView comparison uses official documentation and local equivalent tasks; it does not claim matching private algorithms or pixels.
