# 0.15.0 drawing workflow upgrade

Local functional, installed-package/framework, real-backend and performance checks passed. This version has not been published to npm. KLineCharts remains 10.1.0 and the built-in catalog remains 56 tools.

## Fib levels and content

Fibonacci retracement and extension gain a single-selection level editor with 1–64 rows, finite custom ratios, stable IDs, visibility, color, width, line style and optional single-line text per level. Add, remove and reorder remain drafts until one confirmed update; one undo restores the entire edit. Removing a row with text asks for confirmation. Other Fib and Gann tools retain numeric arrays.

Linear/log calculation is explicit and independent of the price-axis display. Reverse, left/right extension, background, prices, ratios, text, label alignment and position are configurable. Retracement keeps full-pane lines by default; extension keeps its second-to-third-anchor span and three-point guide. Invalid enabled projections retain their definitions and show a reason instead of fabricated values. Disabled rows are not projected; an entirely hidden object remains editable in the tree.

Retracement uses `b+(a-b)r`, with a/b swapped for reverse; log uses `exp(log(b)+(log(a)-log(b))r)`. Extension uses `c+(b-a)r`, with the difference negated for reverse; log uses `exp(log(c)+(log(b)-log(a))r)`. Background bands use adjacent enabled prices in sorted order, skip zero-area duplicates and do not expand hit regions or axis ranges.

Templates, defaults and recent styles contain appearance only, without row IDs or text. Object copying preserves text with a fresh logical ID. Full-template application matches ratios in repeated-occurrence order, preserving matching IDs/text and creating fresh empty rows. Removing an unmatched row containing text rejects the entire preflight. Style-only application changes no levels, parameters or text.

## Preferences and persistence

DrawingPreferences becomes v2 with `ui.snapping={ohlc:true,indicators:true,weakSensitivity:8}`. The pure `migrateDrawingPreferences` helper accepts v1/v2; initial input and store.read accept either, while writes/state use v2. Edits made before the initial read merge by changed field. Corrupt or unknown documents fail explicitly and retain the original for the existing retry flow.

ChartLayoutV4, Workspace v2, shared drawings v1 and alerts v1 keep their versions. Legacy arrays and missing parameters remain readable without materializing level objects on read. The first actual level edit writes `{version:1,items:[...]}`. The real 0.14 reader rejects that new structure without overwriting storage; do not assume a downgrade can open newly edited level documents.

## Entry points and snapping

The picker supports direct favorites and the last 12 tools. Category buttons prefer the current tool, then the latest tool in that category, then its first catalog entry. The toolbar exposes continuous drawing and matching pre-draw templates. `executeDrawingCommand({type:'tool',toolId,templateId})` validates before replacing a preview and captures the template for the session; each continuous object gets fresh row IDs and no copied text. Cancellation, identity/binding changes and disposal end the session, and late confirmation cannot advance a replacement session.

Snap sources independently select OHLC or visible indicators. Weak distances are 4/8/12/16 CSS pixels; strong mode retains nearest-candidate behavior without a distance limit. Ctrl/Meta keeps the existing temporary toggle. Only confirmed data and valid visible results on the same pane and actual axis are candidates; an independent axis never borrows the main OHLC. Both sources off shows an explicit message. Preferences do not edit anchors, history or annotations. Escape closes the menus and restores trigger focus, including at 320px.

## Generic integration

A third-party descriptor can declare `kind:'level-set'` under any parameter key and render through public `resolveDrawingLevels` plus the peer engine's `registerOverlay`. Omitted capabilities do not infer an editor from a tool name. The standalone drawing-workbench `EXAMPLE/LevelBands` demonstrates numeric-array/v1 preference reading, editing, text-free templates, undo, native persistence and independent owner teardown without private DTOs or services.

EvoTrader Fib objects remain locally owned and persist through existing workspace/shared documents. Existing line/rectangle annotations retain backend authority; no new annotation types, trading actions, account calculations, alert conditions or cloud service are introduced.

## Local performance results

The complete final run on 2026-10-28 passed all 172 obligations: the previous 166 plus two mixed-translation improvements and four 64-level trusted-handle drag targets. No budgets changed. Sampling was serial on Node 24.14.0, Chromium 147.0.7727.15 and CPUs 8/9/16/17 with isolated synthetic market inputs. Real-backend workflows were checked separately.

For 10k/50k bars, maximum mixed-translation latency across 20 samples was 1219.2/1130.2ms, improving on the designated complete 0.14 baseline by about 21.1%/29.2%. The four 64-level drag combinations each retained 200 samples, with p95 values of 100.8/101.6/101.8/101.9ms against 150ms. Restoring 1002 objects with 50k bars took at most 788.2ms with a 196ms longest task, retaining the original 0.13 denominator and 808.65/200ms targets. Both 100-cycle cleanup workloads passed.

These are local results under the stated conditions. Original failures and complete arrays remain in the evidence listed by the root repository's upgrade SUMMARY.
