# 0.16.0 level alerts (local candidate)

This candidate is not published. Use `npm install trading-chest@0.15.0 klinecharts@10.1.0` for the published release. Build and pack this repository, then install the actual `trading-chest-0.16.0.tgz` to try the candidate. The catalog remains at 56 tools.

## Confirmed level selection

Fibonacci retracement and extension support one stable level per alert through the existing properties, editor and alert manager. The selector shows row number, ratio and text preview; equal ratios retain distinct IDs. Confirm or cancel editor drafts before adding alerts. Legacy arrays and omitted levels remain read-only until the user explicitly initializes them, waits for confirmation and selects a level. Initialization is one undoable update. Rejection, uncertainty or changing the source never creates an alert. Valid persisted IDs remain stable regardless of a `legacy-` or `default-` prefix.

Anchor, ratio, calculation, reverse or extension changes clear the comparison point; the next valid observation seeds it. Style, text and ordering preserve it. Hidden/deleted levels disable their rules; restoring the original ID requires explicit resume. Resume retains deduplication, rearm clears it. Event ratio/text are snapshots at trigger time.

The evaluator uses confirmed closes. Retracement is `b+(a-b)r`; extension is `c+(b-a)r`. Log calculation applies these formulas in log-price space independently of the displayed axis. Reverse swaps retracement endpoints or negates the extension difference. Finite domains are closed timestamp intervals: first/second anchors for retracement, second/third for extension. Explicit left/right extensions remove their corresponding bounds. All anchors must be within loaded/replay history. Invalid log prices, overflow and unavailable projections report a reason.

Log levels retain exact endpoint and flat-anchor prices; other log results use isolated high-precision arithmetic before conversion to numbers. Adjacent floating-point prices remain distinct. Settings, defaults, Alt+L and same-instance layout restoration immediately revalidate a changed price axis and clear comparisons while retaining live/replay markers. Unprojectable sources disable their rules and require explicit resume after axis recovery; valid rules await a new confirmed observation. An already-open alert manager also blocks initialization, creation and saving while the editor has a draft, preserving the selection until confirmation or cancellation.

## Generic instance capabilities

A data-only catalog descriptor declares `alertLevels:{resolverId,parameterKey}` pointing to one actual `kind:'level-set'` parameter. No formula is inferred from tool/parameter names. Register pure synchronous functions with construction-time `drawingAlertLevelResolvers`; React forwards this option through `initialOptions` and keeps the mounted instance across renders.

A resolver receives copied `toolId` (actual overlay name), market `anchors`, selected `level` and `parameters` completed using the current instance catalog defaults. Return `{status:'ready',referencePrice,from?,to?,comparisonKey}` or `{status:'unavailable',reason}`. Price/bounds must be finite, the optional millisecond bounds form a closed interval, and omitted bounds are infinite. The nonempty comparison key includes every geometry-affecting parameter, excluding appearance/text/order. Throws, promises or malformed output make the source unavailable without fallback. Duplicate/empty IDs reject construction; built-in IDs `tradingchest/fibonacciLine` and `tradingchest/fibonacciExtension` cannot be replaced. Missing resolvers preserve drawings and report unavailable alerts.

Reduced built-in Fib catalogs may omit geometry controls: the renderer and built-in resolver share omitted defaults, with declared instance defaults taking precedence. Custom resolvers receive no injected Fib fields. Rejected promises/thenables are isolated while still failing synchronous resolution. Pure evaluation requires all two/three market anchors for the built-in retracement/extension resolver; custom single-anchor tools remain supported.

`examples/drawing-workbench/level-bands.mjs` shares pure mathematics with its renderer, uses arbitrary parameter `zones` and declares a finite domain. The second workbench has different defaults. `alerts.html` demonstrates both Fib tools, custom levels, callbacks and native IndexedDB save/dispose/restore using only the installed public package.

## V2 documents and migration

`captureDrawingAlerts()` returns V2; `restoreDrawingAlerts()` accepts V1/V2. Pure `migrateDrawingAlertDocument` returns an isolated V2 copy, adds `{kind:'line'}` to V1 rules and retains IDs, scope, identity, messages and live markers. Level targets contain `{kind:'level',resolverId,parameterKey,levelId}`. Create accepts only levelId and derives the capability binding from the instance; changing a rule's source/target requires a new rule.

Malformed documents, unknown fields/versions, duplicate IDs, invalid markers and scope mismatch reject atomically. The intentional change from 0.15 is that structurally valid unavailable sources/levels/resolvers are preserved as disabled rules with reasons. Restore never repairs drawings, drops rules or triggers events. Resume revalidates identity and keeps markers; a triggered once rule requires rearm.

Save layout and alerts separately, preferably restoring layout first. Reverse order retains disabled/unavailable rules. Provide a stable isolated `drawingAlertScope` for cross-instance restore; the default is a random instance scope. Layout/workspace/shared/preferences remain v4/v2/v1/v2. The actual 0.15 package rejects V2 while retaining existing rules. The combined example also validates source completeness before replacing its whole bundle; independent runtime imports permit unavailable sources.

`trading-chest/alerts` exports evaluation, migration, Fib price/domain mathematics and built-in resolvers without DOM, KLineCharts, Solid or React. Direct callers add `target` to rules and `kind:'line'` to line geometry; level geometry includes its target, reference price/domain, comparison key and event snapshot values. Root/chart/solid expose the applicable helpers/types too.

Alerts run only while this page is open, with separate live/replay state and callbacks. They do not backfill history, execute trades, send notifications or guarantee tick-level touches. Multilevel compound rules remain outside this version.
