# 升级到 0.10.0

本版集中改进绘图：统一的 51 工具目录、图内多行文字、控制点和精确坐标编辑、对象管理、多选分组、模板偏好，以及显式的本图／工作台／宿主共享。KLineCharts 固定 10.1.0。版本号和本地构建不表示 npm 或 Pages 已发布。

## 从 0.9.0 迁移

- 布局公开入口切换至 `ChartLayoutV4`，命名工作台切换至 `WorkspaceDocument` v2。新布局使用 `drawings`、`drawingPresentation` 和可选 `sharedDrawingRefs`；工作台另存单份 `sharedDrawings`。不要继续读取 `chart.overlayData`。后端内容仍来自宿主 authority，布局只保存呈现与引用。
- 使用 `migrateLayoutToV4`、`captureLayout`／`restoreLayout` 和 `saveLayoutV4`／`loadLayoutV4`。旧图表 v1/v2/v3、工作台 v1 可纯读取迁移；旧存储原件保留，成功保存后写新格式。仅有 dataIndex 的旧点必须结合原历史解析，不能猜交易日期。旧 `saveLayoutV3` 不再从公开入口导出。
- 通过 `commitDrawing` 或 `restoreDrawings` 接入用户内容；直接创建的宿主系统覆盖物不会因同名 ID 自动变成可写对象。目录以实例为单位；自定义工具先注册真实模板并提供目录描述。
- 程序和 UI 共用 `executeDrawingCommand`。检查 `completed/partial/rejected/uncertain/cancelled` 及逐项结果；已确认前缀不会自动补偿，未知写入不自动重发。旧 undo/redo 方法与命令共用队列，切换上下文后取消排队的旧历史操作。
- `onDrawingSelect` 在多选时通知 null。`onDrawingStateChange` 提供完整副本状态；`onDrawingHistoryChange` 跟随实际操作会话。共享迁移的连续 undo/redo 保留原操作历史，显式选择其他对象会改变目标。

默认快捷键：Alt+T 趋势线（有限线段）、Alt+H 水平线、Alt+V 垂直线、Alt+F Fib 回撤、Alt+R 矩形、Alt+B 连续画笔、Alt+C 十字线、Shift+M 测量。测量从 Alt+M 改为 Shift+M，Alt+C 改为创建十字线；不再同时切换原十字光标。Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl/Cmd+C/V 保留，输入框继续使用原生撤销与剪贴板。实例偏好可以覆盖工具组合，重复或浏览器保留组合会明确拒绝。

## 持久化与共享

偏好默认仅本次会话有效。显式创建首方 IndexedDB preferences store 并传入不透明 `drawingPreferencesScope`，即可保存模板、收藏和快捷键。图表借用 store，所有者在最后一个借用者离开后 dispose；SSR 不打开 IndexedDB。

宿主共享需显式 `DrawingSessionRegistry`、`DrawingDocumentStore` 及 `resolveDrawingShareKey`。共享身份包含 namespace、完整 market/exchange/ticker/priceCurrency 和已确认价格口径；缺少身份或口径时显示原因。共享仅适用于主价格窗格的 local 市场锚点，保存原价格值，由各图主价格轴投影，不持有某张图的 engine axis ID。副图、未来逻辑根数和视口文字保持本图；后端标注继续走原 chart_context 与标注 API。

HTTP store 的 null expectedRevision 表示“只创建”，非无条件覆盖。保存响应丢失后按固定 documentId 读取核对，草稿或迁移恢复记录不会自动改道。示例见[独立绘图工作台](https://github.com/evotrader/TradingChest/tree/main/examples/drawing-workbench)；HTTP 部分仅在 loopback 开发服务可用，进程退出即清空示例记录。

## 数学与输入行为

回归按已加载真实 OHLC 做 OLS 与总体残差标准差；Fib、通道和音叉先在原价格域计算，再按实际轴投影。测量分开根数与自然时长。多空头仅显示价格、显式 tick、百分比和盈亏比，不计算账户数量或杠杆。无效方向、零风险和非正 log 派生值显示原因。

Enter／按钮完成可变点工具，Esc 取消，空格临时平移。控制点支持方向键与 Shift 10px 微调，拖动结束只提交一次。中文组合输入期间 Enter 不确认，多行文字支持 Ctrl/Cmd+Enter。未来区域只显示后续根数，参考 bar 缺失时保留对象并允许重试。

本版按 TradingView 的高频绘图流程对标，仍有[明确差距](../drawings-coverage.md)。成交量分布、Anchored VWAP、曲线／圆弧、更多 Gann/Fib/波浪、图片、画线报警和订单联动属于后续候选，不能将 51 工具描述为全部 TradingView 工具等价。
