# 升级到 0.11.0

本版增加锚定 VWAP、固定区间成交量分布，以及分组折叠、虚拟对象树和确认排序。目录由 51 增至 53 项，KLineCharts 保持 10.1.0。完整数值与状态契约见[量价绘图](../drawings.md#volume-drawings)。本地版本材料不表示已经对外发布。

## 接入与迁移

无需新增 Datafeed 方法：两工具仅消费本图 loader 已确认的 OHLCV。成交量须存在、有限且非负；没有成交量的源仍能使用旧工具，选择新工具时会显示不可计算原因。单位未知时只显示“数据源成交量单位”。这不是逐笔或更细周期成交量分布，也不提供真实主动买卖量。

ChartLayoutV4、WorkspaceDocument v2 与共享文档 v1 继续保存定义。新增工具 ID 为 `anchoredVwap`、`fixedRangeVolumeProfile`；参数和市场锚点随原文档保存，派生曲线、分箱和状态不持久化。0.10 旧工具无需迁移；旧版本无法识别新工具时应保留原文档并明确报错，不应丢弃工具后覆盖保存。

`DrawingState.analytics` 是可选的只读副本摘要，按 logicalId 索引；`DrawingAnalyticsState` 等类型从根、`chart`、`solid` 入口导出。它不承诺完整历史覆盖，`period` 在行情尚未确认时可缺失。

绝对排序通过 `{type:'reorder', ids, targetId, position:'before'|'after'}`，按对象树显示顺序解释位置。旧 direction 命令继续有效。只允许同文档、同作用域、同 pane、同组的可写对象；锁定、迁移或 uncertain 对象拒绝排序。确认前的变化会重新预检，undo/redo 共用原历史。

## 使用与限制

两工具只接受主图真实市场时标。拖动和坐标编辑只改变时间，端点价格不参与公式。回放只使用可见前缀，未到右端显示部分区间；退出回放重新计算。跨周期只共享定义，各图按自己的 bar 时标重新采样，不复制源图数值。

对象树折叠仅对本次会话有效；搜索暂时展开命中组。键盘方向键、Home/End 保留虚拟列表焦点。鼠标／触点拖排与目标选择器消费同一个确认排序命令，取消不写历史。保存范围、CAS、unknown 写核对和借用资源释放仍按 0.10 契约。

暂不提供标准差带、更细周期或逐笔分布、曲线圆弧与画线报警。TradingView 对照基于官方文档与本地同类任务；不声称算法或像素完全相同。
