# 升级到 0.12.0

本版增加统一单选／多选样式编辑、AVWAP三组带、FRVP显示设置，以及curve／doubleCurve／arc。目录从53增至56项，KLineCharts保持10.1.0。原Datafeed、HistoryResult和HTTP签名无需变化；本地候选不表示已发布npm。

## 兼容与接入

ChartLayoutV4、WorkspaceDocument v2、共享文档v1和偏好v1继续有效。旧AVWAP缺少带参数时等价none；旧FRVP缺显示字段时保持左侧、30%宽度与原价位线显示。新参数与曲线沿原anchors/styles/parameters保存；未知工具、算法或非法参数会报错并保留存储原件，不能删除未知定义后覆盖保存。

自定义目录可补充`styleControls`以声明实际支持的描边、填充、线宽／型、文字颜色／字号。未声明保留旧常规能力，空数组表示无快捷样式。模板消费原标准样式键；跨工具模板只能显式应用共同样式，不复制正文、坐标或参数。color参数仅支持#RRGGBB/#RRGGBBAA或transparent。

第三方模板须先通过peer `klinecharts::registerOverlay`登记，再构造使用相同稳定命名空间名称的drawingCatalog。缺模板在DOM创建前失败；销毁图表不删除全局模板。参见[原生JS/TS示例](https://github.com/evotrader/TradingChest/tree/main/examples/drawing-workbench)。

## 数学与交互

AVWAP保留原source和中心，新增source价格按volume加权的总体标准差带，以及中心绝对值百分比带。最多三组，数值不可表达时保留中心并报告带不可用，不夹成正数或伪造零宽。FRVP显示位置、宽度和价位线样式／延长不改变分箱或统计范围。

曲线在当前投影屏幕坐标中定义，持久化仍只存锚点。curve点击起点、终点、控制点；doubleCurve增加第二控制点；arc第三点位于弧上。退化保定义与控制点，真实绘制和命中共用有界线段。详见[公式与完整参数](../drawings.md#drawing-refinement)、[曲线](../drawings.md#curves)及[能力差距](../drawings-coverage.md)。

批量操作继续逐对象确认，一次事务一次undo/redo，pending、拒绝、unknown和共享权限不改变。内部呈现合并不改变公开通知顺序。对象树、宽／窄图、键盘及原生IndexedDB保存仍为同一流程。
