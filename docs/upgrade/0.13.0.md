# 0.13.0：画线提醒与绘图响应性

本页描述 0.13 本地候选。npm 发布是单独动作，不能将本地构建或示例通过视为已发布；已发布的 0.12 不含这些新增 API。

## 接入画线提醒

图上选择绘图后使用“添加提醒”，或打开“提醒管理”。首批支持 `horizontalStraightLine`、`straightLine`、`segment`、`rayLine`；仅本图、主价格窗格默认轴、market 锚点，含原 market 插值。可以绑定 local 或原 authority 已确认的 backend 来源，保持 owner/backendId，不写标注或订单接口。

```ts
const result = chart.executeDrawingAlertCommand({
  type: 'create', drawingLogicalId: 'host-opaque-drawing-id',
  condition: 'crossing-up', frequency: 'once-per-bar', message: '突破关注线'
})
if (result.status === 'rejected') console.error(result.message)
```

条件是 crossing/crossing-up/crossing-down；频率是 once/once-per-bar。一次已触发的规则必须 rearm；pause/resume 保留已触发及最近 bar 标记，rearm 清标记但保留实例触发历史。update 仅改条件、频率和消息，条件／频率改变重建比较点而不清去重标记。所有新规则、resume/rearm、恢复、数据中断恢复和确认移动后的首个有效观测只建立比较点。

评估仅使用收到的 close，包含同根 close 替换；不从 OHLC 高低点推断路径，不承诺逐笔触达、收盘确认、页面关闭后的运行或历史补报。线段有界，射线遵循原方向；休市间隔按真实 bar 位置计算。对数轴在 log 价格域插值，百分比／线性轴沿价格仿射域，反向不颠倒价格穿越方向。

## 无 DOM 评估与持久化

`trading-chest/alerts` 提供 `evaluateDrawingAlert`、规则／事件／文档类型和 `validateDrawingAlertDocument`，ESM/CJS 均不运行时依赖 KLineCharts、Solid、React、CSS 或存储。调用方提供规则、确认几何、真实 bar 时标、前后观测、既有标记及轴类型；函数返回新标记、可选比较点和最多一个事件，不投递通知。

图表通过 `onDrawingAlertStateChange`、`onDrawingAlertTrigger`、`onReplayDrawingAlertTrigger` 通知宿主。live/replay 的比较点、标记和最多100条实例记录相互隔离。事件的 barTimestamp 是行情时标；不把本地接收时刻当成逐笔时刻。

规则默认只在内存中。`captureDrawingAlerts/restoreDrawingAlerts` 使用独立 `DrawingAlertDocumentV1`，宿主要跨重开恢复时传入稳定、不透明的 `drawingAlertScope`。恢复全批预检、失败保原，成功一律暂停并保去重标记。ChartLayout v4、workspace v2、shared v1、preferences v1 均不新增提醒字段；单独保存布局不保存提醒。绘图工作台新增 `alerts.html` 展示同一原生 IndexedDB 事务保存，以及独立暂存图表完成布局与提醒恢复后才采用；失败保原图和原存储。

## 快照身份检查

`Datafeed`、HTTP 和 `ChartSnapshot` 签名不变。快照现在按 ticker/market/exchange/priceCurrency 的实际可选值及周期匹配；未声明字段不能冒充已声明身份。异步读取前捕获真实请求身份和周期，返回时连同该身份调用 applySnapshot，不能给旧响应重新贴上当前身份。

同身份 HTTP 完整快照仅末根替换或新增一根时可以评估；一次补多根、更早历史修订或 basis 变化只重建最新比较点。snapshot 内部逐根写不逐根补报。断线、读取错误、revisionRequired、恢复及未确认数据暂停评估；状态通知不重复消费价格。

## 曲线表现

三种原曲线增加 startMarker/endMarker（none/arrow/circle，默认 none）、background（默认 false）、backgroundOpacity（有限[0,1]，默认0.12）。背景沿标准 `overlay.styles.polygon.color`，默认沿实际描边；区域是曲线和两端直弦闭合区域，不延伸到价格基线或 pane 边缘。端点沿实际曲线切向朝外，尺寸随实际线宽限定在6–18 CSS px。背景不抢命中，标记不是新控制点；退化不绘制假标记。

旧定义保持原外观，目录仍56工具。参数沿原设置、模板、确认、共享和持久化路径，不改变曲线定义、0.5px误差及2048段上限。跨工具“仅共同样式”模板仍只传能力交集；完整参数模板用于同工具。

响应性改动保持原逐对象确认、权限检查、结果顺序和一次批处理一次撤销。性能结论应读取实际完整样本和实施 SUMMARY；本页不以功能或安装包通过替代性能验收。
