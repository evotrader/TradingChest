# 0.15.0 绘图工作流升级

本地功能、安装包／框架、真实后端及性能验证已通过，尚未发布到 npm。KLineCharts 保持 10.1.0，内置工具仍为 56 个。

## 两种 Fib 的级别编辑

斐波那契回撤和扩展增加单选级别表：1–64 行，自定义有限比例，稳定 ID，显隐、颜色、宽度、线型和每级单行正文。新增、删除、排序留在草稿内；确认为一次修改，可一次撤销，取消不写入。删除有正文的级别先确认。其它 Fib、江恩等工具沿用原数字数组。

计算方式显式选择线性或 log，与价格轴显示方式独立。可反向、左右延长、填充背景，调整价格／比例／正文、标签对齐和位置。回撤默认左右延长；扩展默认保留第二至第三锚点横区间及三点引导。无效 log 锚点或不可投影的启用级别保留定义并说明原因；不会画伪造值。关闭级别不参与投影，全关闭的对象仍能从对象树编辑。

回撤为 `b+(a-b)r`，反向交换 a/b；log 为 `exp(log(b)+(log(a)-log(b))r)`。扩展为 `c+(b-a)r`，反向改变差值符号；log 为 `exp(log(c)+(log(b)-log(a))r)`。背景按启用价位排序，相邻重复值不画零面积带，不扩大命中或价格轴范围。

## 正文与模板

级别正文属于对象。模板、工具默认和最近样式只保存级别外观，不保存 ID／正文；复制对象则保留正文并产生新的 logicalId。完整模板按比例及重复出现顺序匹配现有行，保留匹配行 ID／正文，新行使用新 ID 和空正文。若会移除带正文的行，整批预检拒绝并指出对象；共同样式应用不改级别、参数或正文。

`executeDrawingCommand({type:'tool',toolId,templateId})` 支持绘前模板。模板须属于该工具，校验失败保留当前预览；开始时捕获副本，连续新建仍使用该定义并为每个对象生成新行 ID。取消、身份／绑定变化及销毁结束该会话，迟到确认不会启动新会话的下一对象。未指定模板沿最近样式、工具默认和宿主／引擎默认的原优先级。

## 偏好与旧文档

DrawingPreferences 升至 v2，新增 `ui.snapping={ohlc:true,indicators:true,weakSensitivity:8}`。`migrateDrawingPreferences` 是纯读取迁移；构造参数及 store.read 可接收 v1，store.write 和运行状态只提供 v2。初读前的本次编辑按字段合并；损坏／未知版本明确失败并保留原件，可沿原重试入口处理。

ChartLayoutV4、Workspace v2、SharedDrawingDocument v1、提醒 v1 不升版。旧数字数组及缺省参数可读取，打开设置不改写；首次实际改级别才写入 `{version:1,items:[...]}`。旧 0.14 读取新对象结构会拒绝，且不覆盖原存储；回退前应保留原文档备份，不能假定新级别对象可由旧版加载。

## 工具入口与吸附

全部工具内可直接收藏，最近使用保留 12 项，类目按钮优先当前工具、同类最近工具、目录首项。收藏、只选绘前模板和调整偏好不产生内容历史。连续绘制可在工具栏切换，作用于当前会话后续确认；移动收藏栏等其它偏好不重置显式选择。

吸附设置可分别选择 K 线 OHLC 和可见指标，弱磁距离为 4／8／12／16 CSS px；强磁保留不限距离最近候选。Ctrl／Meta 沿原临时切换语义。候选只来自当前已确认行情及同 pane／实际同轴的有效可见结果，独立轴不借主轴 OHLC；两来源均关显示“未选择吸附来源”。设置不移动已有锚点，不写标注。

## 开源接入

第三方在 `DrawingToolDescriptor.parameters` 任意键显式声明 `kind:'level-set'`，使用公开 `resolveDrawingLevels` 与 peer `registerOverlay` 即可。省略能力时不根据工具名推导编辑器。见 [独立级别带示例](../frameworks.md#drawing-workbench-example) 的 `EXAMPLE/LevelBands`，不依赖 EvoTrader DTO／服务。

EvoTrader 的两个 Fib 保持 local owner，通过原工作台／共享文档保存；不增加 AnnotationType 或 Fib 后端接口。原线／矩形仍由后端确认。实盘、订单、资金、提醒条件与云服务不在本次升级范围。

## 本地性能结果

以下为独立审计前首次收口的历史结果，修后当前结果见下一小节。2026-10-28 的完整采样保留原 166 条义务，新增两条千对象混合平移改进与四条 64 级可信控点拖动，共 172/172 通过，当时未调整预算。Node 24.14.0、Chromium 147.0.7727.15、CPU 8/9/16/17，串行采样，使用隔离合成行情；真实后端流程另行验证。

1 万／5 万根历史下，千对象混合平移各 20 次的最大延迟为 1219.2／1130.2ms，相对指定 0.14 完整基线改善约 21.1%／29.2%。64 级拖动四个组合各 200 次，p95 为 100.8／101.6／101.8／101.9ms，均低于 150ms。5 万根、1002 对象的全量恢复最大延迟为 788.2ms、最长主线程任务 196ms，仍使用原 0.13 分母及 808.65／200ms 目标。两组各 100 次清理通过。

以上为固定条件下的本地结果；全部原始失败与完整数组保留在根仓本轮 SUMMARY 所列证据中。

### 独立审计后的修复与当前预算

修复跨 calc 函数替换后旧异步结果仍被吸附认可的问题；另存／布局重绑在更换文档前取消未确认预览，迟到确认不能写入后继；Fib 初始、连续及空格恢复预览使用实例目录并保留参数／级别 ID。三项经修后独立复核均已闭合。

受影响的45条性能义务重新采样后，原门槛为42／45。2026-10-28操作者接受仅三条绝对上限：5万根／1002对象恢复900ms、其完整最长任务250ms、1万根／1002对象混合平移1550ms。完整原数组实际为862.6／237／1492.6ms，按批准标准重判45／45；其余127条复用未受影响的原正式证据，共172条义务满足新标准，200次清理通过。没有重新采样全部172条，也没有改写原失败。

恢复和1万根混合平移不再承诺必达10%改善；实测仍较固定原分母改善约4.0%／3.4%，但新上限本身不保证改善。恢复最长任务237ms比原0.13的182ms更长约30.2%。5万根混合平移仍保留10%目标，实际1147.9ms低于1437.12ms。其余169条门槛不变。功能、三浏览器、安装包／六消费者和真实后端24场景通过；后端验证包含预期空／错状态，不表示全部网络请求成功。尚未发布npm。
