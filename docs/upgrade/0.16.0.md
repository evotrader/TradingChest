# 0.16.0 单级提醒升级（本地候选）

本页描述本地候选，验收结果见本次实施记录；尚未发布到 npm。已发布版本为 0.15.0，正式安装仍用 `npm install trading-chest@0.15.0 klinecharts@10.1.0`。试用本版需在本仓库构建后 `npm pack`，再安装实际生成的 `trading-chest-0.16.0.tgz`。内置工具仍为 56 项。

## 选择一个已确认级别

Fib 回撤和扩展可从原属性栏、对象设置或单级“添加提醒”按钮进入提醒管理。级别选择显示行序、比例和正文短预览，重复比例由稳定 ID 区分。选择来源、级别、穿越条件和频率后创建；有未提交编辑草稿时先确认或取消。

旧数字数组和缺省级别只读打开不会写入。点击“初始化级别”经原提交确认后，需要重新选择一级再创建提醒；一次初始化可撤销。拒绝、待确认或切换来源后不会自动创建。已有 `legacy-*`、`default-*` ID 只要存于有效级别表，就视为稳定身份。关闭面板不会回滚已经确认的初始化。

修改比例、锚点、计算方式、反向或延伸会清除比较点，下一有效行情只建立起点；颜色、正文与排序不清除观察。隐藏或删除目标级别会停用规则；恢复该 ID 后须手动继续。继续保留去重，重置并启用清除去重。事件正文与比例保存触发瞬间的值。

提醒仅使用确认系列的 close。回撤公式为 `b+(a-b)r`，扩展为 `c+(b-a)r`；log 模式在价格对数空间计算，独立于图表价格轴。反向回撤交换 a/b，反向扩展改变差值符号。有限时间域使用闭区间，回撤取第一到第二锚点，扩展取第二到第三锚点；左右延长显式决定无限方向。锚点必须都在已加载／回放历史范围内，非正 log 价格、溢出和不可投影来源明确不可用。

对数级别保留端点和同价锚点的原价，其余结果经高精度计算后转为数值；到价与从等价离开的判断不合并相邻浮点价格。设置、恢复默认、Alt+L或同实例布局恢复改变价格轴时，立即重检来源并清除比较点，保留实时／回放触发标记。不可投影的来源停用，切回原轴不会自动启用；可用规则等待下一条确认行情建立起点。提醒管理已经打开时，编辑器的新草稿也会阻止初始化、创建和保存，确认或取消后可继续，原选择保留。

## 第三方能力与无框架接口

纯数据目录声明 `alertLevels:{resolverId,parameterKey}`，parameterKey 必须指向实际 `kind:'level-set'` 参数。不按工具名或参数名猜测公式。每个实例在构造时传入 `drawingAlertLevelResolvers`，函数与注册数组为实例所有，React 通过 `initialOptions` 沿原构造生命周期传入。

```ts
const descriptor = {
  // 其余目录字段见 examples/drawing-workbench/level-bands.mjs。
  alertLevels: { resolverId: 'example/level-bands', parameterKey: 'zones' }
}
const resolver = {
  id: 'example/level-bands',
  resolve: ({ anchors, level, parameters }) => ({
    status: 'ready',
    referencePrice: anchors[1].value +
      (anchors[0].value - anchors[1].value) * level.value,
    comparisonKey: JSON.stringify([anchors, level.value])
  })
}
```

解析器收到隔离副本：实际 overlay name、市场 anchors、选中级别，以及按当前实例目录补齐的 parameters。同步返回有限 referencePrice、可选毫秒 from/to（缺省方向无限）及非空 comparisonKey；或 `{status:'unavailable',reason}`。comparisonKey 必须包含影响本工具几何的全部参数，不能包含外观、正文、排序。返回 Promise、抛错、非有限数或无效结构会明确不可用，不回退其它解析器。内置 ID `tradingchest/fibonacciLine` 和 `tradingchest/fibonacciExtension` 不可覆盖；空 ID／重复 ID 拒绝构造。声明缺失解析器的绘图仍可编辑，提醒显示缺失原因。

精简内置 Fib 目录可省略不需要的几何控件，提醒和画布使用相同的缺省值，实例显式默认值仍优先；第三方解析器不会被注入 Fib 字段。误返回的拒绝 Promise／thenable 会被隔离，仍作为同步解析失败处理。直接调用纯评估器时，内置回撤／扩展解析器必须保留完整的2／3个市场锚点；自定义解析器仍可声明合法的单锚点工具。

完整示例 `examples/drawing-workbench/level-bands.mjs` 与画布共用数学并声明有限时间域；三个工作台中的第二实例使用不同默认值。`alerts.html` 演示普通 OHLCV、两种 Fib、任意 `zones` 参数、事件回调以及原生 IndexedDB 保存／销毁／恢复。

## V2 提醒文档

`captureDrawingAlerts():DrawingAlertDocumentV2`；`restoreDrawingAlerts(V1|V2)` 先完整验证后替换。`migrateDrawingAlertDocument` 是无写入的深复制迁移，V1 四线规则补 `{kind:'line'}`，保留全部身份、消息和实时去重标记。V2 级别目标为 `{kind:'level',resolverId,parameterKey,levelId}`。规则换来源／目标须新建；create 只接受 levelId，另两个字段由实例目录取得。

结构错误、未知版本／字段、重复 ID、非法标记或 scope 不匹配整批拒绝并保留原状态。与 0.15 的差异：结构合法但来源、级别或解析器暂不可用的规则也完整恢复为未启用，并显示原因；不自动修复来源、不丢规则、不触发。恢复后手动继续再次检查来源身份。已触发 once 须重置并启用。

布局和提醒分别保存；建议先恢复布局，再恢复提醒，反序也不丢规则。应用为跨实例恢复提供稳定且隔离的 `drawingAlertScope`，缺省为当前实例随机 scope。布局／工作台／共享／偏好格式分别保持 v4／v2／v1／v2。0.15 实际旧包拒绝 V2 并保留原规则。`alerts.html` 的组合保存例子另有来源完整性预检，以实现示例自身的整包替换保证；这不是 runtime 对独立提醒导入的限制。

`trading-chest/alerts` 导出纯评估、迁移、两种 Fib 数学和内置解析器，无需 DOM、KLineCharts、Solid 或 React。直接调用评估器时 line geometry 新增 `kind:'line'`，rule 新增 target；级别 geometry 需携带 target、价格／时间域、comparisonKey 和事件快照值。root/chart/solid 同时导出适用类型与 helper。

仅当前页面监控，不是后台任务、逐笔触达保证、交易指令或消息服务。实时／回放状态和回调分离，不补报历史。当前版本没有多级组合提醒。
