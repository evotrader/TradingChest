# 0.17.0 多图联动复盘

0.17 是本地候选版本。发布状态以 npm 实际记录为准，本次本地升级不包含发布。KLineCharts 继续使用 10.1.0，无新增运行时依赖。

## 启用与时间语义

为原生 `ChartWorkspace` 或 React `TradingWorkspace.initialOptions` 设置 `replay: {enabled: true}`。默认关闭；旧 Datafeed 无须实现新方法。控制条提供范围、驱动图、速度、播放/暂停、步进、定位与返回实时；`toolbar.replay`、`toolbar.notes` 可分别隐藏界面，公开 API 仍可用。Solid 入口也导出 ChartWorkspace 与相同类型。

这是已完成 K 线的当前历史复盘。历史可能经过修订或复权，绘图与笔记可能含事后认识；它不重建 PIT 数据版本，不模拟盘中路径或交易撮合。所有时间使用整数 UTC 毫秒。显示时区仅影响输入呈现；DST 重复时刻要求选择偏移，不存在的时刻拒绝提交。

Datafeed 可选实现 `getReplayHistory(symbol, period, query, context)`；DataSession 同名方法省略 symbol/period，通过同一个 active session 转发。

```ts
// query: {from, to, warmupBars}; context: {signal, reason: 'enter'|'restore'}
return {
  bars, // 当前实例同源、同复权口径的 KLineData[]
  clocks, // 与 bars 一一对应的 {timestamp, completedAt, availableAt?}[]
  identity, // 完整 SeriesIdentity，不含路径或密钥
  basis,
  historyKind: 'current-history',
  metadata: {state: bars.length ? 'ready' : 'empty'},
  coverage: {from, to, warmupBars: actualWarmupCount},
}
```

可见时刻为 `max(completedAt, availableAt ?? completedAt)`。返回 `[from,to)` 内全部可见时刻，以及此前最后至多 warmupBars 根；预热范围 0–1000，界面默认 200。coverage 必须覆盖完整请求窗口，不表示每分钟都有 bar。缺少 availableAt 时界面提示按完成时刻近似。不要用抓取时间、周期长度推算或最终 OHLC 冒充来源时钟。

timestamp 严格递增，完成及可见时刻沿序列非递减；错误、错配、未知完成时刻、部分覆盖、身份/basis 不一致整体拒绝。取消后忽略迟到结果。所有比较成员也须实现同一能力；不支持的成员会指出原因，需用户在实时模式移除后重试。

## 工作台 API

```ts
await workspace.startReplay({from, to, cursor, driverCellId})
workspace.playReplay()
workspace.pauseReplay()
await workspace.stepReplay('forward') // 或 backward
await workspace.seekReplay(timestamp)
workspace.setReplaySpeed(4) // 1、2、4、8、16 步/秒
workspace.setReplayDriver(cellId) // 暂停时切换
await workspace.stopReplay()
await workspace.resumeReplay() // 保留上次记录和书签 ID
const unsubscribe = workspace.subscribeReplay(state => { /* 消费状态副本 */ })
```

getReplayState/onReplayStateChange 使用同一状态：mode 为 live/replay，phase 为 idle/loading/paused/playing/seeking/resuming/error。cursor 是全局时刻，不等于任一窗格最后一根标签。驱动图决定下一步，各窗格只展示自身已可见前缀；休市/空 follower 不填假数据。只有一个播放调度器，隐藏页面自动暂停。

异步命令在全部窗格、比较、指标与绘制完成后 resolve。任一失败保留上次成功状态；回滚失败保持 error 遮层，可重试 stopReplay 恢复真实来源。强制卸载直接 dispose。复盘期间锁定布局、标的、周期和比较成员增删。宿主更换 context 前 await stopReplay，失败保留原宿主。同步 `removeComparison` 在存在复盘记录时拒绝 BUSY；界面删除先完成保留/放弃记录的交互，原普通调用不受影响。

单图 `ChartPro.stopReplay()` 现在返回 `Promise<void>`，调用方须 await 或处理 rejection。工作台持有期间逐图 startReplay/stopReplay 拒绝 REPLAY_OWNED，getReplayEngine 返回 null；旧单图模式继续可用。

## 事件、笔记和持久化

分析事件/点在工作台复盘中须同时满足 timestamp 与 availableAt 不晚于 cursor。缺少 availableAt 不展示，并说明原因。比较基准只取当时真实共同 timestamp。没有可用时刻的 TradeVis 覆盖物隐藏，退出恢复原可见性。普通图与旧单图回放保留原语义。

侧栏可按窗格、图层、标题筛选已可见事件。定位保留事件原始 timestamp，按 `max(timestamp,availableAt)` 推进；不把邻近 K 线伪装为事件时刻。书签只存引用与纯文本，不保存第三方 payload。

- `getReplayRecord()` 返回副本；`updateReplayNotes(notes)` 更新会话备注。
- `addReplayBookmark({timestamp,title,note,cellId?,eventRef?})` 返回稳定 ID；`updateReplayBookmark(id,patch)`、`removeReplayBookmark(id)` 编辑或删除。
- `navigateReplayEvent({cellId,layerId,eventId})` 定位已可见事件；引用失效明确拒绝，已存书签仍保留。
- 标题 120 字、书签备注 4000 字、会话备注 20000 字、最多 1000 书签；越界拒绝，不截断。应用草稿后还需保存工作台。

WorkspaceDocument 升至 v3，增加可选 replaySession；v1/v2 读取纯迁移，不自动覆盖存储原件。ChartLayoutV4、绘图、提醒文档不升版。播放中保存为 paused；暂停记录恢复时重新读取原来源，成功后才整体替换当前工作台。live 记录打开不读取旧时钟，可显式继续上次复盘。保存不含 bars、时钟数组、timer、订阅或已触发提醒；恢复不自动启用提醒。仍使用已有 store scope、revision、CAS 和结果未知处理。

## 宿主与示例

库接口不依赖 EvoTrader。`examples/analysis-sdk/replay-workspace.html` 使用明确的合成行情，包含不同交易时段/周期、比较、延迟事件、失败重试、笔记与 IndexedDB；React Vite 示例使用相同公共能力，支持 StrictMode。示例数据不能当作生产回退。

EvoTrader 的 live、backtest、只读成交入口接入原 Catalog 与原同步 journal。首批有逐 bar 来源时钟的实现为 `us-yfinance-history-clock-v1`。普通无钟来源会明确拒绝统一复盘，普通图表仍可用。当前历史不是 PIT 证据。图表所在订单表单在进入/复盘/恢复期间禁用，并在最终提交时重新读取状态；退出完成后仍遵守原账户和订单权限。
