# 从 0.6.0 升级到 0.7.0

KLineChart 继续固定 10.1.0；现有实时续读、比较、回放、确认绘图和 v3／workspace 存储保持。此版本新增通用分析 API，不接管业务计算或数据服务。

1. 安装配套 trading-chest 0.7.0 和 klinecharts 10.1.0，保留 CSS 导入。推荐纯图表入口 trading-chest/chart；React／Solid 仍用已有入口。
2. 可选传 indicatorCatalog；省略保留内置全目录。指定目录时，必须包含初始化和布局中实际使用的指标。外部模板在构造前以命名空间登记。实例 API 返回真实 ID，设置和删除改按 ID，不能按名称假定唯一。参数 defaults 沿模板，MA 四项／RSI 三项，可变长布局不补尾项。
3. 在 onDataReady 后取得 getAnalysisContext，用当前 token 添加分析层。标的／周期／确认 basis 变化后旧 handle 失效，释放并重新提供；同口径刷新不用重建。宿主仍负责 HTTP／WS、取消、返回顺序和结果归属。
4. 时间序列显式声明 placement/valueType；main price 需要相同已知 dataBasis。日期结果用 label-series，保留原值，不猜交易时刻或币种。回放 availability 规则同时作用于画布、列表、点击和 tooltip；没有精确可用时刻的标签层隐藏。
5. 分析数据和显隐不持久化，不需要新增数据库迁移。v3 根据真实运行时 ID 排除指标／pane／axis；宿主重新提供分析快照。旧绘图和后端标注引用保持，不能为恢复清理用户数据。
6. ChartWorkspace 的 height 默认改为 100%。父容器必须给明确高度；若旧宿主依赖固定高度，显式传 number。locale/theme/toolbar 只控制 workspace chrome，cell 自有布局恢复语义保持。

`npm run test:browser` 自行启动包内 Vite、选择空闲端口，从本包解析 @playwright/test 并归档 trace／JSON。缺少浏览器或测试依赖会失败，先 `npx playwright install chromium`。独立 tarball 消费示例见[快速开始](../getting-started)。

性能保留上一轮有效上限：普通 10k 单图冷初始化 265.60000002384186ms，50k 单图和 10k／50k＋3 比较冷初始化 500ms；更新、交互和多图原预算不变。tests/browser/performance-budgets.json 保存原精度与出处；旧 baseline 参数只作兼容来源，不重复套倍率放宽。新增分析负载先验控制组原预算，再比较同环境增量。100 次释放检查自有资源；GC 可用时记录堆趋势，不能据此宣称所有浏览器永久零泄漏。

`npm run test:performance` 自行启动服务并依次运行原单图／比较／工作台及新增分析配对负载；时间采样期间不启用 trace，避免测量开销改变预算。

2026-10-17 操作者批准仅将新增分析负载双图的冷初始化上限设为：每图 10k 为 350ms、每图 50k 为 750ms。其余 46 个性能门槛保持原值，包括控制组、分析单图、更新与交互；以上两项不再使用配对 cold 增量公式。预算文件的 analysisColdOverrides 记录范围和出处，输出同时保留原增量上限与批准记录。

仅预算变更、产品及测量条件未变时，可运行 `node tests/browser/performance.mjs --recheck-analysis <原始完整分析采样.json> <新结果.json>`。脚本核四场景的完整采样、原统计值和释放结果后，以采样同一判定逻辑重算；不启动浏览器、不覆盖原结果，也不将重算表述为重新测量。
